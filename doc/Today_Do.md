
### 📍 Phase 1: Foundation & Assessment (Month 1-2)

> Build your base. Plug gaps. Set a prep routine.

✅ **Topics to focus:**

- DSA: Arrays, Strings, Hashmaps, Linked Lists, Recursion
    
- Java internals (or your language): OOP, Collections, Multithreading
    
- CS Fundamentals: Time/Space complexity, Big-O, basic DB queries
    

📘 **Resources:**

- Neetcode 150 – beginner sections
    
- [CS50 by Harvard](https://cs50.harvard.edu/x/) – optional, but solid
    
- Clean Code book – read 2 chapters
    

🎯 **Target Output:**

- Solve 100 basic-medium Leetcode problems
    
- Build 1 small project like a URL shortener / blog API using Spring Boot
    
- Create your own study Notion or GitHub notes
    

🧠 **Blooms Tip:** Focus on **understanding** and **applying**

---

### 📍 Phase 2: Intermediate Skill Building (Month 3-6)

> Now start solving **harder problems** and work on **systems and design**

✅ **Topics to cover:**

- DSA: Trees, Graphs, Sliding Window, Two Pointers, Heaps, Tries
    
- System Design (Beginner): Caching, Rate limiting, APIs
    
- DB: Normalization, Indexing, Joins
    
- Core OS Concepts (optional): Threads vs Processes, Scheduling
    

📘 **Resources:**

- Leetcode + Neetcode (medium-hard)
    
- [System Design Primer GitHub](https://github.com/donnemartin/system-design-primer)
    
- Spring Boot + JPA practice with real-world models (e.g. inventory, orders)
    

🎯 **Target Output:**

- 200-250 total Leetcode problems solved (track tags & patterns)
    
- 1 full-stack project deployed (e.g. Expense Tracker, Stock Watcher)
    
- Write 3 blog posts or internal tech notes (to train your "explain" skills)
    

🧠 **Blooms Tip:** Practice **applying** and **analyzing** problems. Don’t just solve—ask “why does this work better?”

---

### 📍 Phase 3: Advanced Prep & Mock Interviews (Month 7-10)

> Level up to handle actual interviews at MAANG-type bar

✅ **Topics to master:**

- Advanced DSA: DP, Backtracking, Union Find, Advanced Trees
    
- System Design: End-to-end design of Notification System, Instagram Feed, etc.
    
- Behavioral prep: STAR format, Amazon LP stories, Product thinking (Apple)
    

📘 **Resources:**

- Grokking System Design
    
- [AlgoExpert](https://www.algoexpert.io) (optional)
    
- Cracking the Coding Interview (select chapters)
    

🎯 **Target Output:**

- Mock interviews weekly (with friends or Interviewing.io)
    
- Complete 3–4 real system design case studies (write them down!)
    
- Write out 10+ behavioral stories using STAR
    

🧠 **Blooms Tip:** Focus on **evaluating** tradeoffs in design/code choices

---

### 📍 Phase 4: Application & Interview Mode (Month 11-12)

> Now simulate real hiring situations and prep company-wise

✅ **Action Plan:**

- Company-specific rounds: Google = more DSA, Amazon = LP+DSA, Apple = UX Design + Engineering Depth
    
- Resume polishing – tailor for SDE-2 impact and clarity
    
- Start mock system designs as whiteboard sessions
    

🎯 **Target Output:**

- Resume reviewed by mentor or senior
    
- Apply to 10+ companies
    
- Do 10+ mock interviews (DSA + Design + Behavioral)
    
- Build a GitHub + portfolio that shows clean, production-level code
    

🧠 **Blooms Tip:** Focus on **creating** your own answers and **critiquing** interview approaches.
