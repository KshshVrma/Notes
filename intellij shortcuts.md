
[[Intellij]]
### 🔍 **Navigation Flashcards**

**Q:** What shortcut opens any file by name?  
**A:** `Ctrl + Shift + N` (Mac: `Cmd + Shift + O`)

---

**Q:** What shortcut helps you go to a class quickly?  
**A:** `Ctrl + N` (Mac: `Cmd + O`)

---

**Q:** Shortcut to go to a method/variable definition?  
**A:** `Ctrl + B` or `Ctrl + Click` (Mac: `Cmd + B`)


### ⚙️ **Code Editing Flashcards**

**Q:** What shortcut triggers auto-completion?  
**A:** `Ctrl + Space`

---

**Q:** Shortcut to generate getters, setters, constructors?  
**A:** `Alt + Insert` (Mac: `Cmd + N`)

---

**Q:** How do you surround code with `try-catch`, `if`, etc.?  
**A:** `Ctrl + Alt + T` (Mac: `Cmd + Option + T`)

---

**Q:** What’s the shortcut to reformat code?  
**A:** `Ctrl + Alt + L` (Mac: `Cmd + Option + L`)

---

**Q:** Shortcut to rename a variable/class safely?  
**A:** `Shift + F6`

---

### 🔄 **Search & Refactor Flashcards**

**Q:** What shortcut opens Search Everywhere?  
**A:** `Double Shift`

---

**Q:** Shortcut to replace text across project?  
**A:** `Ctrl + Shift + R` (Mac: `Cmd + Shift + R`)

---

**Q:** How to open refactoring menu quickly?  
**A:** `Ctrl + Alt + Shift + T` (Mac: `Ctrl + T`)

---

### 🧪 **Run & Debug Flashcards**

**Q:** Shortcut to run your app?  
**A:** `Shift + F10`

---

**Q:** Shortcut to debug your app?  
**A:** `Shift + F9`

---

**Q:** During debugging, how to step _over_ a line?  
**A:** `F8`

---

**Q:** During debugging, how to step _into_ a method?  
**A:** `F7`

---

**Q:** How to evaluate variable value in debug mode?  
**A:** `Alt + F8`

---
